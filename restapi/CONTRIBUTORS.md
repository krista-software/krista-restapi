# Contributors

We appreciate all contributions to the RestApi Extension for Krista project! This document recognizes the individuals and organizations who have contributed to making this project better.

## How to Contribute

We welcome contributions in many forms:

- **Code contributions** - Bug fixes, features, and improvements
- **Documentation** - Improving guides, examples, and API documentation
- **Testing** - Writing tests, reporting bugs, and testing new features
- **Community** - Helping other users, answering questions, and providing feedback
- **Translations** - Translating documentation to other languages
- **Design** - Improving UI/UX and visual design

See [CONTRIBUTING.md](CONTRIBUTING.md) for detailed guidelines on how to contribute.

## Recognition

### Core Contributors

The RestApi Extension for Krista was developed and is maintained by the Krista Software team.

### Community Contributors

We recognize all community members who have contributed to this project through:
- Pull requests and code reviews
- Issue reports and feature requests
- Documentation improvements
- Testing and quality assurance
- Community support and engagement

### How to Get Recognized

If you've made a contribution and would like to be recognized:

1. Ensure your contribution is merged or accepted
2. Add yourself to this file in the appropriate section
3. Include a brief description of your contribution
4. Submit a pull request

## Contribution Guidelines

All contributors agree to:

- Follow the [Code of Conduct](CODE_OF_CONDUCT.md)
- Respect the [License](LICENSE) (GPLv3)
- Follow the [Contributing Guidelines](CONTRIBUTING.md)
- Maintain code quality and test coverage
- Provide clear commit messages and documentation
